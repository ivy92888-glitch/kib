# Kib · 今天学一点，宠物长一点

> 一款把「学习闯关」与「宠物养成 · 城市经营」结合起来的游戏化学习应用（PWA）。
> 在轻松地养宠物、建城市的过程中，每天坚持学一点，让知识和宠物一起成长。

**在线体验**：https://ivy92888-glitch.github.io/kib/

---

## 项目简介

Kib 是一款**游戏化的知识学习应用**。它把「刷题 / 背词 / 练听力」这类原本枯燥的学习行为，包装成一套有正向反馈的养成游戏：学完一个单元就能赚金币，用金币领养宠物、经营城市、解锁成就。核心设计目标是「**让坚持学习变得像玩游戏一样自然**」。

整个应用是一个**纯前端的单文件 PWA**，无需服务器、无需数据库、无需任何外部依赖，打开即用、断网可玩、可添加到手机主屏幕当 App 使用。

---

## 核心玩法

```
学习闯关  ──►  赚金币  ──►  养宠物 / 建城市  ──►  解锁成就  ──►  继续学习
```

1. **闯关学习**：选择一个知识领域，按单元闯关答题，答对通关、解锁下一关。
2. **赚取金币**：每关通关、连续打卡都会获得金币奖励。
3. **宠物养成**：用金币领养宠物，给它洗澡、理发、做体检、喂零食，陪它长大。
4. **城市经营**：建造小房子、商店、游乐园、知识灯塔等建筑，把城市越建越大。
5. **成就系统**：通过连续打卡、通关数量等行为解锁成就徽章，形成持续的正向激励。

## 技术栈与架构

| 维度 | 实现 |
| --- | --- |
| **前端** | 原生 HTML / CSS / JavaScript（无框架、无构建工具） |
| **架构** | 单文件 SPA，6 个内联脚本模块组织业务逻辑 |
| **PWA** | Web App Manifest + Service Worker（离线缓存、添加到主屏幕） |
| **数据存储** | localStorage 本地持久化（纯本地，进度不离开设备） |
| **后端** | 无（零后端、零外部依赖、零 API 调用、零 CDN） |
| **体积** | 全量自包含，含题库、游戏逻辑、宠物 / 城市资源，可整体分发部署 |

---

## 技术亮点

1. **单文件自包含**：一个 `index.html`（约 6.5MB）内含完整题库、全部游戏逻辑与多套宠物 / 城市视觉资源，做到「一个文件即一个完整应用」，部署与迁移成本极低。
2. **纯前端离线可用**：借助 `localStorage` + Service Worker，无需任何服务器或数据库即可运行，断网状态同样可玩，进度本地留存。
3. **游戏化设计**：构建「学习 → 金币 → 养成 / 经营 → 成就」的完整正向循环，参考多邻国式绿色激励风格，让坚持学习有即时反馈。
4. **内容工程化**：将 40+ 知识分类、数千道题目、20+ 宠物品种、近 20 种建筑、100+ 徽章作为结构化数据内嵌，数据与渲染逻辑解耦，便于持续扩充内容。
5. **PWA 体验**：支持添加到手机主屏幕、全屏 standalone 运行、离线访问，接近原生 App 的使用体验。

## 快速开始

### 在线体验

直接访问：**https://ivy92888-glitch.github.io/kib/**

手机端可打开链接后，通过浏览器菜单「添加到主屏幕」，即可像 App 一样使用。

### 本地运行

本项目是纯静态站点，任意静态服务器即可运行，例如：

```bash
# 进入项目目录后，用 Python 起一个本地静态服务
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

或者直接双击 `index.html` 在浏览器中打开（部分浏览器对本地 PWA 特性有限制，建议用本地静态服务器）。

## 数据与隐私

- 所有学习进度、金币、宠物、城市等数据均保存在**浏览器本地**（localStorage），不经过任何服务器、不上传云端。
- 应用**不收集任何个人信息**，不包含任何网络请求、统计埋点或第三方 SDK。
- 更换设备或清除浏览器数据会导致本地进度丢失（本地存档特性所致）。
